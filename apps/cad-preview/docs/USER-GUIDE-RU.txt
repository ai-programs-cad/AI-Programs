CAD Preview for Windows 0.4.0 — руководство

Windows 10/11 x64. Установка требует прав администратора.
Программа работает с DXF, STL, STEP и STP. DWG не поддерживается.
AutoCAD, SOLIDWORKS, .NET и Python конечному пользователю не требуются.

УСТАНОВКА
Закройте просмотрщик и окна Проводника с предпросмотром CAD. Запустите Setup.exe.
Выберите Explorer thumbnails и/или Explorer preview pane. При конфликте установщик
спросит о замене обработчика. Приложение для открытия файла по умолчанию не меняется.
В Проводнике включите панель Alt+P и выберите файл; миниатюры видны в крупных значках.
При сохранении старого обработчика в памяти перезагрузите Windows в удобное время.

УПРАВЛЕНИЕ
Левая кнопка + движение: вращение 3D, перемещение DXF.
Колёсико: масштаб. Нажатое колёсико + движение: перемещение.
Двойной щелчок колёсиком или F: вписать целиком с сохранением ракурса.
Правая кнопка: меню. Controls help: Hide / Show controls.
Все подсказки и команды просмотра на английском.

DXF отображается на постоянном тёмном фоне. Меню: Fit to window, Zoom in/out,
File information, Controls help, Layers. Мелкая геометрия не удаляется.
STL/STEP: янтарная поверхность, рёбра и светлый градиент по умолчанию.
Show edges: рёбра; Wireframe: каркас. Contrast model color возвращает исходные
цвета STEP или стандартный цвет STL. Light gradient background отключает градиент,
после чего можно выбрать однотонный фон. Настройки вида сохраняются.
STL-рёбра выделяются на границах и перегибах от 30 градусов, без плоских диагоналей.

File information показывает компактную панель: имя, размер, формат, габариты,
единицы и статистику геометрии. Close или повторная команда закрывает панель.
Текст можно копировать. Если Windows передала безымянный поток, имя не выдумывается:
будет указано CAD file (Explorer stream).
Отдельный просмотрщик: Open file, Fit to window, View и File information.

ИСХОДНЫЕ ФАЙЛЫ И ОГРАНИЧЕНИЯ
Файлы открываются только для чтения. Геометрия и исходные файлы не изменяются.
Поддерживается подмножество ASCII DXF; Binary DXF и ряд сложных сущностей/кодировок
не поддержаны. Единицы STL могут быть не заданы. Лимит входного файла 256 MiB;
для сложных моделей действуют ограничения времени, памяти и количества примитивов.
Очень тяжёлые модели могут загружаться медленно или превышать лимиты.

Windows может блокировать панель для файлов с меткой загрузки из Интернета.
Для доверенного файла используйте Свойства > Разблокировать, если такой пункт есть.
Глобальное отключение защиты не требуется. Старые миниатюры могут храниться в кэше.

УДАЛЕНИЕ
Параметры Windows > Приложения > CAD Preview for Windows > Удалить.
Сохранённые прежние машинные обработчики восстанавливаются при удалении;
пользовательские настройки и изменения других CAD-программ могут иметь приоритет.

СТОРОННИЕ КОМПОНЕНТЫ
Программа использует Open CASCADE Technology 7.9.3, LLVM/mingw runtime и NSIS.
Сохраняйте лицензии, уведомления, соответствующие исходники OCCT и инструкции
его сборки из полного комплекта. Коммерческие условия самого приложения пока не заданы.

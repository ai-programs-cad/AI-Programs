Сборка CAD Preview for Windows x64

Проверенная конфигурация этой рабочей сессии:
Windows x64, LLVM-MinGW 20261006 UCRT (Clang 23.1.3), CMake 4.4.4,
Ninja 1.13.2, OCCT 7.9.3, NSIS 3.11.
MSVC, полный Windows SDK, Qt и vcpkg не требуются для этого пути сборки.
LLVM-MinGW содержит Windows API заголовки и библиотеки mingw-w64.
В системе обнаружен только dotnet runtime, без SDK, поэтому он не используется.

Загрузки для разработчика (не устанавливайте их пользователям программы):
https://github.com/mstorsjo/llvm-mingw/releases/download/20261006/llvm-mingw-20261006-ucrt-x86_64.zip
https://github.com/Open-Cascade-SAS/OCCT/archive/refs/tags/V7_9_3.zip
https://downloads.sourceforge.net/project/nsis/NSIS%203/3.11/nsis-3.11.zip
https://cmake.org/download/
https://github.com/ninja-build/ninja/releases

Распакуйте инструменты. Распакуйте third_party/OCCT-7.9.3-source.zip.
В PowerShell запустите из папки проекта (подставьте реальные абсолютные пути):

./scripts/build.ps1 -CompilerDirectory C:/tools/llvm-mingw-20261006-ucrt-x86_64 -CmakeDirectory C:/tools/cmake/bin -NinjaExecutable C:/tools/ninja/ninja.exe -OcctSourceDirectory C:/tools/OCCT-7_9_3

Сценарий собирает необходимые OCCT toolkit DLL, затем все приложения,
создаёт цветную STEP-сборку и запускает CTest. Число параллельных заданий
можно уменьшить параметром -Parallel 2 при нехватке памяти.
Выключенный CADPREVIEW_WITH_OCCT допускается только для разработки DXF/STL:
такую сборку нельзя распространять как поддержку всех форматов.

Для упаковки:
./scripts/package.ps1 -BuildDirectory ./build/app -OcctBuildDirectory ./build/occt -OcctSourceDirectory C:/tools/OCCT-7_9_3 -CompilerDirectory C:/tools/llvm-mingw-20261006-ucrt-x86_64 -NsisDirectory C:/tools/nsis-3.11

Результат: dist/portable и dist/CADPreview-0.3.2-dev-x64-Setup.exe.
package.ps1 создаёт точный список файлов для деинсталляции и SHA256-манифест.
Установщик компилируется без установки продукта и без изменения реестра.
Для выпуска следует добавить проверку Authenticode, подписать DLL/EXE
и повторить приёмку уже подписанного установочного пакета.

Обычная сборка CMake с MSVC также предусмотрена:
cmake -S . -B build-msvc -A x64 -DOpenCASCADE_DIR=C:/path/to/occt/cmake
cmake --build build-msvc --config Release
Этот вариант в текущей среде НЕ выполнялся; бинарные OCCT должны быть собраны
совместимым компилятором. Не смешивайте C++ ABI MSVC и LLVM-MinGW.

Модули единого проекта:
CADPreview.Core — модель сцены, границы, контроль ресурсов, бинарный обмен;
src/dxf.cpp, stl.cpp, step.cpp — форматные модули DXF/STL/STEP;
CADPreview.Renderer — проекция, освещение, Z-buffer, интерактивный viewport;
src/settings.cpp — настройки пользователя;
CADPreview.Worker — отдельный импорт и генерация миниатюр;
CADPreview.Shell — две COM-класса, общий код Thumbnail Provider/Preview Handler;
CADPreview.Viewer — автономное приложение Windows;
installer — единый установщик; tests — ядро, COM, Worker и модели.
DXF/STL/STEP являются модулями одной библиотеки, а не несовместимыми проектами.

Тестовые DXF/STL уже включены. При изменении генератора их можно пересоздать:
python tests/generate_fixtures.py
Python нужен только разработчику, не установщику и не конечному пользователю.

Текущая рабочая сборка была выполнена из work/cad-build,
OCCT — work/occt-build родительской рабочей папки. Эти каталоги временные;
сценарий выше позволяет выполнить новую сборку независимо от них.

Для повторной сборки приложения при уже собранном OCCT доступен проверенный
прямой путь LLVM-MinGW без CMake:
./scripts/build-existing-occt.ps1 -CompilerDirectory C:/tools/llvm-mingw-20261006-ucrt-x86_64 -OcctBuildDirectory C:/build/occt -OutputDirectory C:/build/cad
Именно этим сценарием пересобраны бинарные файлы 0.3.2, поскольку доступ
к прежней локальной установке CMake оказался ограничен правами файлов.

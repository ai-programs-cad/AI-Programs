# AI Programs — бесплатные инструменты для повседневной работы

Я сделал эти программы для себя: это задачи, с которыми я постоянно сталкиваюсь в работе. Инструменты помогают выполнять их быстрее, и теперь я делюсь исходниками, чтобы ими могли пользоваться и улучшать другие люди.

- **CAD Preview:** миниатюры и просмотр DXF, STL, STEP прямо в Проводнике Windows.
- **CNC File Doctor:** преобразование сплайнов в гладкие полилинии с заданным допуском, стремление к небольшому числу элементов, проверка контуров DXF. Глобально минимальное число элементов не гарантируется.
- **PartCraft:** развёртки листового металла с линиями гиба; DXF выбранных параллельных граней с отверстиями, пазами и карманами; наглядное задание на нарезку профилей с количеством деталей.
- **Макросы:** экспорт DXF, сведения о деталях, нарезка профилей, переименование Cut List/тел.

Эта открытая версия не требует оплаты, активации и не ограничена пробным сроком. Для PartCraft и макросов нужен собственный лицензированный SolidWorks 2025.

Пользователи могут предлагать улучшения через Issues и Pull requests. Изменения включаются в основную версию после проверки. Условия: GPLv3 или более поздняя версия; исключение для работы с SolidWorks API описано в LICENSE-NOTICE.md.

Инструкции сборки — docs/BUILD.md. Известные ограничения — docs/STATUS.md. Исходные модели пользователей в комплект не входят.

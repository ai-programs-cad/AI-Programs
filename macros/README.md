# SOLIDWORKS macros

The editable VBA module text is extracted from the exact SWP projects included here. No macro was executed during extraction.

- Flat_DXF: native flat-pattern DXF export.
- Part_info: part information; inspect the VBA main routine before running it.
- Profiles+h: legacy profile cutting cards based on a selected drawing table.
- RenamePlusN: Cut List/body names and N properties; this changes model data. Test on a copy.
- StileDXF: plain-text DXF export layer mapping.

Use the SOLIDWORKS VBA editor to inspect/edit the SWP project. Export updated modules for readable pull-request reviews. A .bas extraction alone is not a promise that a whole VBA project with forms/references can be reconstructed by simply renaming the file.
